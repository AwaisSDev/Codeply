Questions

What exactly does Codeply do?

Codeply is an autonomous coding agent. Give it a task in plain English and it reads your codebase, writes and edits files, runs commands, and keeps going on its own until the task is actually done. Not just suggests where to paste something.

How is this different from a code-completion tool?

Codeply doesn't just generate a suggestion and stop. It acts: it edits files and runs commands on your project directly. With Codeply Craft, it goes a step further and opens the page it just changed in a real browser panel, reads back console errors and failed requests, and fixes them before it calls the task done.

Does Codeply work with my editor?

Codeply isn't tied to a specific editor. Use the codeply terminal CLI on any project on disk, or Codeply Craft, the desktop app with a chat interface, project and session management, and a docked browser panel. It works with whatever language the project's files use.

Does it actually see the page, like a screenshot?

No. Codeply Craft's self-check reads real signal from the browser: console errors, failed network requests, and broken images. Not a picture of the page. It's demonstrable, not a visual guess.

Will it change my files without asking?

By default, no. Every write, edit, and command asks for your approval first, with a visible diff before anything touches disk. There's an optional bypass mode if you want Codeply to just run without stopping to ask.

What's the difference between the CLI and Codeply Craft?

The CLI (codeply) is a terminal-native agent for people who live in a terminal. Codeply Craft is the full desktop app: a chat interface, project and session management, and the docked browser panel that verifies changes. Both share one account.

How does Codeply know which skill to use?

Codeply draws on a library of 280+ specialized skills, from accessibility to security review to TDD workflow to premium web design, and reaches for the right one automatically when a task calls for it. You don't manage it by hand.

Is Codeply a browser extension?

No. Codeply Craft is a desktop app. The browser panel inside it is a real Chromium instance the app controls to verify changes. It's not an extension you install into your own browser.
