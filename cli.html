Get started in minutes

Up and running in 3 steps

1
Install

Run the install command above, or npm i -g codeply if you already have Node.

2
Sign in

Run codeply login and enter your email code. Same account and daily cap as Codeply Craft, sign in once and it works everywhere.

3
Give it a task

Run codeply in any project and describe what you need in plain English. It reads the codebase, writes and edits files, and runs commands. Every change asks for approval by default; pass --bypass if you want it to just run.

Prefer a chat interface with a docked browser panel that verifies every change? Codeply Craft is the desktop app version, same account, same cap.
