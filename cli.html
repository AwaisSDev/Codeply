Up and running in three steps

Step 1

Install

Run the install command. It adds the codeply command.

Step 2

Sign in

Run codeply login and enter your email code. Same account and daily cap as Craft.

Step 3

Give it a task

Run codeply in any project and describe what you need in plain English.

Bring your own model

codeply provider ollama switches to a local or cloud Ollama model with no Codeply cap. codeply apply "<instruction>" --file path runs one scripted edit without an interactive session.

Want the full desktop app?

Codeply Craft adds a chat UI, projects, and a browser panel that verifies every change.
