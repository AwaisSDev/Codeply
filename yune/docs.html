Getting started

Everything you need to go from the installer to your first change.

ON THIS PAGEInstall and sign inThe shortcutWatch a project folderYune Code in the terminalHelp

Install and sign in

  • Download the installer for Windows or macOS from the download page and run it.
  • Sign in with your email. Yune sends a 6-digit code: no password to remember, no API key to paste and no model to pick. The AI is built in.
  • After that, Yune lives quietly in your system tray. It doesn’t need to stay in focus.

The shortcut

  • Press Alt + C (Option + C on macOS) from anywhere and Yune opens in the corner of your screen.
  • Paste a snippet you copied, or type what you want changed in plain English: “make the button blue”, “add a loading spinner here”, whatever it is.
  • Hit Apply. Yune works out which file it belongs in (if you’re watching a project folder), makes a small checked change and writes it.
Every write, edit and command asks first, and a whole message can be undone in one click.

Watch a project folder

Open Settings and set a Watch folder. With a folder watched, Yune can work out which file a pasted snippet belongs in, even across several files in one paste, using your project’s structure and its framework’s conventions. Without one, you can still point it at a specific open file.

Yune Code in the terminal

A real coding agent in your shell. It reads your codebase, edits and creates files, searches for patterns and runs commands, checking its own work along the way.

Install with one line, no npm needed:

# Windows irm https://codeply.app/install.ps1 | iex # macOS, Linux or WSL curl -fsSL https://codeply.app/install.sh | sh
  • Sign in with codeply login. It’s the same account as the app.
  • Run codeply with no arguments for the full interactive agent, or codeply apply "<instruction>" --file path/to/file for a single one-shot edit.
  • Prefer your own model? codeply provider ollama switches to a local or cloud Ollama model.
