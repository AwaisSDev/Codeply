Codeply Studio

The AI code editor. Everything you know from VS Code, with the Codeply agent built into the side panel.

Download See how it works

Also known as Codeply IDE. A VS Code fork with the Codeply engine inside.

An agent in the side panel

Chat in Agent, Plan or Ask mode. It reads your code, edits files and runs commands, and each step waits for your approval. When it is done you see every changed file with its diff, then choose Undo all or Keep.

Ctrl+K, edit in place

Select some code, press Ctrl+K and say what should change. The edit lands right in the file as an inline diff you can Accept or Reject.

1Press Ctrl+K and describe the change
2Accept or Reject the inline diff

Codeply Dark and Codeply Light

Two built-in themes. Pick the one that suits the room.

Use your own models

Start with Auto, or point Studio at the model you already use.

  • AutoThe hosted Codeply model
  • OpenAI-compatibleAny API that speaks the OpenAI format
  • OllamaModels running on your own machine

Tab autocomplete

Suggestions appear as you type. Press Tab to take one.
