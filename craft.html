How it works

Describe it. Craft does the rest.

One agent plans the work, writes the code, runs it and checks it, then hands you every change to keep or undo.

Describe it

Type what you want in plain English. Pick a project, or let Craft find it, and it plans the work before it starts.

It builds and checks

It edits files, runs commands and tests, then opens the page in a real browser panel and reads back console errors, failed requests and broken images.

You keep what you like

Every write, edit and command asks first, with a visible diff. Undo a whole message with one click, or turn on bypass and let it run.

The proof

The proof behind every change.

Craft opens the page it just changed in a real browser panel and reads back real signal. Not a screenshot, not a guess.

  • ✓Console errors are read back and fixed before it stops.
  • ✓Failed network requests and broken images get caught too.
  • ✓Nothing touches disk without you. Every write, edit and command asks first, with a visible diff.
