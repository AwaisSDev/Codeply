Get started in minutes

Up and running in 3 steps

1
Install and sign in

Run the installer, then sign in with your email code. Same account and daily cap as the CLI, sign in once and it works everywhere.

2
Describe a task

Open a project and type what you need in plain English. Codeply Craft reads your codebase, writes and edits files, and runs commands, asking for approval by default before anything touches disk.

3
It checks its own work

After it changes a page, Codeply Craft opens it in a real Chromium panel docked in the app, reads back console errors and failed requests, and fixes what's wrong before calling the task done.
